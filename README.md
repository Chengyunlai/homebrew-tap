# Homebrew Tap for Ops Agent

This repository publishes the Homebrew Formula for
[Ops Agent](https://github.com/Chengyunlai/ops-agent).

## Install

```bash
brew tap Chengyunlai/tap
brew install ops-agent
```

Upgrade an existing installation with:

```bash
brew update
brew upgrade ops-agent
```

The Formula is generated from the latest public Ops Agent release and its
`SHA256SUMS`. The updater runs on a schedule and can also be started manually
from the repository's Actions page.
